# Media

`media/` contains semantic Markdown companions for curated images, documents, and other media.

**This folder stores meaning, not bytes.**

Each note should explain:

- what the asset is
- why it matters
- what concepts are visible or contained
- where it came from
- which memories/principles/projects it relates to

The physical file normally lives under `assets/`.

For the schema, see `SCHEMA.md` and `templates/media.md`.
