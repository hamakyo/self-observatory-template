# Influences

An influence records a word, text, or work the owner chose to retain because it helps describe their current self-understanding.

Record the source, whether authorship is known, a brief paraphrase, and any interpretation that still needs confirmation. Saving a text does not mean endorsing every claim in it. External writing should not be copied wholesale into this repository.

Life.Word imports begin as `status: draft`. The original Notion snapshots remain in local gitignored quarantine.
