# Memory

Durable memory is split by semantic role, not by arbitrary folder taxonomy.

- `episodes/` — concrete events and experiences
- `knowledge/` — reusable factual/explanatory knowledge
- `influences/` — words and works retained as formative references, with provenance and uncertainty
- `patterns/` — repeated structures inferred from evidence
- `principles/` — compact rules used to make judgments

Prefer links between small notes over giant all-in-one documents.
